# sapsan-watch

Ловит подешевевшие билеты на «Сапсан» Москва → Петербург и пишет в Telegram.
Крутится на маленьком VPS, поэтому работает при выключенном ноутбуке.

Ничего не покупает и никуда не логинится — только читает публичную выдачу `pass.rzd.ru`.

## Почему VPS, а не бесплатный GitHub Actions

Проверено вживую: `pass.rzd.ru`, `ticket.rzd.ru` и `www.rzd.ru` не отвечают
на запросы с зарубежных адресов — не отказ, а глухой таймаут. Раннеры GitHub
стоят за границей, поэтому оттуда монитор слеп. Нужна машина с российским IP.

Подойдёт самый дешёвый тариф у любого российского хостера — Timeweb, RuVDS,
Selectel, Beget. Ориентир: 150–250 ₽ в месяц, одно ядро, 1 ГБ памяти,
Ubuntu 22.04 или 24.04. Этого с огромным запасом.

## Установка

Подключиться к серверу по SSH и выполнить:

```bash
curl -sL https://raw.githubusercontent.com/pmcases/sapsan-watch/main/deploy/install.sh | bash
```

Скрипт спросит токен бота и chat_id, проверит, что с этой машины видно РЖД
и Telegram, поставит systemd-таймер на каждые 5 минут и сразу сделает первый прогон.

### Перед установкой завести бота

1. Написать [@BotFather](https://t.me/BotFather) → `/newbot` → получить токен вида `1234567890:AA...`
2. Написать [@userinfobot](https://t.me/userinfobot) — он ответит числом, это `chat_id`
3. **Написать своему новому боту любое сообщение** — иначе Telegram не разрешит ему писать первым

## Управление

```bash
tail -f /var/log/sapsan-watch.log      # что происходит прямо сейчас
systemctl start sapsan-watch           # прогнать вне расписания
systemctl list-timers sapsan-watch.timer   # когда следующая проверка
nano /opt/sapsan-watch/.env            # поменять настройки
systemctl disable --now sapsan-watch.timer # выключить после поездки
```

Настройки читаются при каждом запуске, перезапускать ничего не нужно.

## Настройки

Живут в `/opt/sapsan-watch/.env`.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TRIP_DATE` | `20.09.2026` | Дата поездки, ДД.ММ.ГГГГ |
| `TIME_FROM` / `TIME_TO` | `09:20` / `09:50` | Окно отправления. Ловит все поезда, уходящие в этот промежуток |
| `PRICE_THRESHOLD` | `14000` | Ниже этой цены — громкий алерт |
| `DROP_DELTA` | `1000` | Тихий алерт, если цена упала хотя бы на столько с прошлой проверки |
| `PRICE_CEILING` | `30000` | Дороже — вообще не кандидат (отсекает первый класс) |
| `WANTED_CLASSES` | пусто | Коды классов через запятую, например `1Р,1С`. Пусто = все сидячие |
| `DAILY_DIGEST_HOUR` | `10` | Час по Москве, когда приходит сводка «что сейчас по ценам» |

Первые прогоны идут в режиме разведки: `WANTED_CLASSES` пустой, и в лог
выпадают все реальные коды классов с ценами. По ним и настраивается фильтр
на комфорт+ и бизнес — вместо догадок о том, как РЖД называет свои вагоны.

## Что приходит в Telegram

- **Громкий алерт** — нашлась цена ниже порога. Номер поезда, класс, цена, сколько мест, ссылка на покупку.
- **Тихий алерт** — цена просто упала на `DROP_DELTA` и больше.
- **Сводка раз в сутки** — текущие цены по всем подходящим поездам, чтобы видеть, что бот жив.
- **Тревога** — если РЖД не отвечает шесть проверок подряд (примерно полчаса).

Один и тот же алерт не повторяется чаще раза в час.

## Про места у окна

Скрипт подтягивает номера свободных мест и помечает те, что **похожи**
на места у окна: в ряду 2+2 это первое и четвёртое, в 2+1 — первое и третье.
Схемы «Сапсана» местами не совпадают с этим правилом (столики, зоны у тамбура),
поэтому номер в сообщении — подсказка, а не гарантия. Перед оплатой сверься
со схемой вагона.

## Про то, чего бот не может

Цены у «Сапсана» динамические: дешёвые тарифные корзины продаются первыми,
и чем ближе дата, тем дороже. Падения случаются в основном на **возвратах** —
кто-то сдал билет, и его корзина открылась заново по старой цене. Бот ловит
именно такие окна. Гарантировать, что они появятся, он не может.

Покупку бот не автоматизирует сознательно: оплата упрётся в 3-D Secure,
а автоматический выкуп билетов — прямой путь к блокировке аккаунта на РЖД.

## История цен

Каждый прогон дописывает результат в `state.json`. Через пару дней там
видно, как цена ходила.
